Каждое задание лабораторной работы 1 выполнено в качестве отдельного файла,
содержащего решение с вводом и выводом, находящееся внутри функции
Каждое решение может быть открыто и запущено самостоятельно, либо вызвано в главном файле (main_lab1)

Для ввода координат использовать ввод через запятую с пробелом, например:
"Введите координаты первой вершины (x1, y1):"
13.5, 8.2
